Not exactly two arguments → error message **and the correct usage** (e.g. `Usage: linkfarm.sh dir linkdir`), exit **1**; `DIR` does not exist → error with its name, exit **2**; `DIR` is not a directory → error with its name, exit **3**; `LINKDIR` exists but is not a directory → error with its name, exit **3**. Nothing is created in those cases.
