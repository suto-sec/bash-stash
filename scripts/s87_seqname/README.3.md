An optional **third argument** `START` is the number of the first file (default 1). It must be a non-negative integer (digits only, `0` allowed): otherwise an error with the value, exit **5** (checked after the checks of step 2, before renaming anything). Three digits are used at least (`007`), more when the number needs them (`1234`). Wrong number of arguments is now fewer than two or more than three.
