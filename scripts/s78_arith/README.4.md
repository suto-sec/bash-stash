Accept **any odd number of arguments** (3, 5, 7...): `A OP B OP C ...`, evaluated **from left to right** with no precedence (`2 + 3 x 4` is `(2+3) x 4 = 20`). Print the whole expression and the final result: `2 + 3 x 4 = 20`. The same errors apply to every number and every operator (the first wrong one from the left wins, numbers and operators checked in the order they appear); an **even** number of arguments (or fewer than 3) is the usage error (exit 1). A division by zero anywhere stops the script with exit 4.
