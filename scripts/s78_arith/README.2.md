Checks, in this order: not exactly three arguments → an error message **and the correct usage** (e.g. `Usage: arith.sh a op b`), exit **1**; `A` or `B` is not an integer (digits with an optional leading `-`) → an error with the wrong value, exit **2** (`A` first); `OP` is not one of the five operators → an error with it, exit **3**; `/` or `%` with `B` equal to 0 → an error message, exit **4**.
