With `-b` as the **first** argument both directions are listed in one sorted list: `< NAME` for the names only in `DIR1`, `> NAME` for the names only in `DIR2` (the marker, one space, the name), all **sorted by name** (when a name is only in one of them there is no tie). Then the line `N only in DIR1, M only in DIR2` (the directories as written). Exit **4** only when **both** counts are 0, after printing `The names are the same`; otherwise exit 0. Without `-b` everything is as in step 3.
