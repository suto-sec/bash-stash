Checks, in this order: no arguments or more than two → an error message **and the correct usage** (e.g. `Usage: iplog.sh [path] [ip]`), exit **1**; with two arguments, `PATH` is not a directory → an error with its name, exit **3**; the second argument is not an IP address → an error with its value, exit **4**; a single argument that is neither an IP address nor a directory → an error with its value, exit **4**; the script needs `$HOME/auth.log` (one argument) and it does not exist → an error mentioning `auth.log`, exit **2**.
