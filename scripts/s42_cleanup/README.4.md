Options come before `DIR`, in any order: `-n` (dry run) and `-d DAYS` (the age limit instead of 7: files modified **more than DAYS days** ago). `DAYS` must be a positive integer, otherwise an error message that includes it and exit code **4**; an option that is neither `-n` nor `-d` → error message that includes it, exit code **5**. Options are processed left to right: the first error wins.
