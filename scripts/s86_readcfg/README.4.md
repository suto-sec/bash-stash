`-k` as the **only option, first** argument: `readcfg.sh -k FILE` prints every **key** of the file (the text before the first `=` of each non-comment, non-blank line that has an `=`), each once, **sorted**. The file checks 2 and 3 apply (the missing file is exit 2, not a regular file exit 3); `-k` with any number of arguments other than the file is the usage error. An empty file prints nothing.
