Checks, in this order: not exactly two arguments → an error message **and the correct usage** (e.g. `Usage: readcfg.sh file key`), exit **1**; the file does not exist → an error with its name, exit **2**; it exists but is not a regular file → an error with its name, exit **3**; the key is not in the file (not even with an empty value) → an error with the key, exit **4**, and nothing on standard output.
