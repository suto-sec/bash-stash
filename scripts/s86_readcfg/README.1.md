A configuration file has lines `key=value`; lines that **start with `#`** and blank lines are ignored. Write `readcfg.sh FILE KEY`. It prints the value of `KEY`: everything after the **first `=`** of the line (the value may contain spaces and more `=`). If the key appears **several times, the last one wins** (`mode` in `app.conf` is `production`). An empty value prints an empty line. The key must match the whole name before the `=` (`mod` is not `mode`). You may assume the key exists.
