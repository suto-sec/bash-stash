With `-c` as the **first** argument the files are not listed but **copied** to `$HOME/newer`, all into that one directory (the file name only; a file with the same name replaces the earlier one). If `$HOME/newer` does not exist create it first and print exactly `Directory <full path> created`. Print `copied PATH` for each copy (the source path as `find` shows it) and finish with the same summary line as before. Everything else, also the exit code 4 for "nothing newer", is unchanged.
