Checks, before touching anything: not exactly one argument → an error message **and the correct usage** (e.g. `Usage: tgzclean.sh file.tgz`), exit **1**; the file does not exist → an error with its name, exit **2**; it exists but is not a regular file → an error with its name, exit **3**; it is a regular file but **not a gzip-compressed tar** (`tar -tzf` fails) → an error with its name, exit **4**, and the file is left as it was.
