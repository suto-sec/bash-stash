`-u USER` (as the **first two arguments**) turns the script into a yes/no question: print `USER is a member of GROUP` and exit **0**, or `USER is not a member of GROUP` and exit **5**. The match is on the whole name (`ana` is not in a list that only has `anabel`). Nothing else is printed in this mode. The checks 1 to 4 apply to the group and the file as before; `-u` without a user is the usage error (exit 1).
