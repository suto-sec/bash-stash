@@step 1 | The last word
@@readme
Write `lastword.sh FILE`. It prints the **last word** of every line of `FILE` (words are separated by blanks; trailing blanks do not count). A blank line prints a blank line.

`while read -r -a words; do echo "${words[-1]}"; done < file` splits each line into an array.
@@check
ARGS=('poem.txt' 'empty.txt')
COMPARE="stdout exit"
@@solution
#!/bin/bash
while read -r -a w; do
  if (( ${#w[@]} )); then echo "${w[-1]}"; else echo; fi
done < "$1"
@@step 2 | Skip blank lines
@@readme
Change the blank-line behaviour: a blank line (an empty line, or one with only blanks) now prints **nothing at all** instead of an empty line. The other lines print their last word as before.
@@check
ARGS=('poem.txt' 'empty.txt')
COMPARE="stdout exit"
@@solution
#!/bin/bash
while read -r -a w; do
  (( ${#w[@]} )) && echo "${w[-1]}"
done < "$1"
exit 0

@@solution
#!/bin/bash
if (( $# != 1 )); then echo "Error: one file is needed" >&2; echo "Usage: $0 file" >&2; exit 1; fi
[[ -f $1 && -r $1 ]] || { echo "Error: cannot read $1" >&2; exit 2; }
n=0
while read -r -a w; do
  n=$((n + 1))
  (( ${#w[@]} )) && echo "$n: ${w[-1]}"
done < "$1"
exit 0
