@@step 1 | How much is used
@@readme
Write `quota.sh DIR`. It prints `Used: N bytes`, where `N` is the sum of the sizes of all the **regular files** below `DIR` (any depth; `find "$1" -type f -printf '%s\n'` prints the sizes, one per line). Always `bytes`.
@@check
ARGS=('proj' 'proj/sub' 'empty')
COMPARE="stdout exit"
@@solution
#!/bin/bash
total=0
while read -r s; do
  total=$((total + s))
done < <(find "$1" -type f -printf '%s\n')
echo "Used: $total bytes"
@@step 2 | Against a limit
@@readme
`quota.sh DIR LIMIT` takes the limit in bytes as a second argument and prints three lines: `Used: N bytes`, `Limit: L bytes` and `OK` when `N <= L` or `OVER` when it is bigger.
@@check
ARGS=('proj 5000' 'proj 4000' 'proj 3999' 'proj 100' 'empty 0' 'empty 10')
COMPARE="stdout exit"
@@solution
#!/bin/bash
total=0
while read -r s; do
  total=$((total + s))
done < <(find "$1" -type f -printf '%s\n')
echo "Used: $total bytes"
echo "Limit: $2 bytes"
if (( total <= $2 )); then echo OK; else echo OVER; fi

@@step 4 | Percentage and exit code
@@readme
Add a line `Usage: P%` between `Limit` and the verdict, with `P = 100 * used / limit` (integer division). With a limit of 0 there is no division: print `Usage: 0%` if nothing is used and `Usage: 100%` otherwise. Finish with exit code **5** when the verdict is `OVER`, and 0 otherwise.
@@check

@@solution
#!/bin/bash
if (( $# != 2 )); then echo "Error: a directory and a limit are needed" >&2; echo "Usage: $0 dir limit" >&2; exit 1; fi
[[ -e $1 ]] || { echo "Error: $1 does not exist" >&2; exit 2; }
[[ -d $1 ]] || { echo "Error: $1 is not a directory" >&2; exit 3; }
[[ $2 =~ ^[0-9]+$ ]] || { echo "Error: '$2' is not a non-negative integer" >&2; exit 4; }
total=0
while read -r s; do
  total=$((total + s))
done < <(find "$1" -type f -printf '%s\n')
if (( $2 > 0 )); then pct=$((100 * total / $2)); elif (( total > 0 )); then pct=100; else pct=0; fi
echo "Used: $total bytes"
echo "Limit: $2 bytes"
echo "Usage: $pct%"
if (( total <= $2 )); then echo OK; exit 0; fi
echo OVER
exit 5
