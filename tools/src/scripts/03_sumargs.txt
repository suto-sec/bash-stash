@@step 1 | Add them up
@@readme
Write `sumargs.sh`: it adds all the integers it receives as arguments and prints

```
Total: 15
```

for `sumargs.sh 4 5 6`. With no arguments it prints `Total: 0`.

`"$@"` is the list of all arguments. A loop goes through it (`for n in "$@"; do ... done`) and `$(( total + n ))` does the arithmetic. Test with positive integers only.
@@check
ARGS=('' '5' '1 2 3' '10 20 30 40' '007 3')
COMPARE="stdout exit"
@@solution
#!/bin/bash
total=0
for n in "$@"; do
  total=$((total + n))
done
echo "Total: $total"
@@step 2 | At least one number
@@readme
With **no arguments** the script is a mistake: print an error message **and the correct usage** on standard error and exit with code **1** (nothing on standard output).
@@check
ARGS=('' '5' '1 2 3' '10 20 30 40')
COMPARE="stdout exit errmsg"
extra_check() { [[ $REF_CODE == 1 ]] && { [[ $ERR == *sumargs.sh* || $ERR == *sage* || $ERR == *Uso* || $ERR == *uso* ]] || fail "the message should show the correct usage"; }; }
@@solution
#!/bin/bash
if (( $# == 0 )); then
  echo "Error: no numbers given" >&2
  echo "Usage: $0 number..." >&2
  exit 1
fi
total=0
for n in "$@"; do
  total=$((total + n))
done
echo "Total: $total"
@@step 3 | Only numbers
@@readme
Every argument must be a non-negative integer (only digits). If one is not, print an error message that includes the offending argument on standard error and exit with code **2**, without printing a total. Check **all** arguments before adding.

`[[ $n =~ ^[0-9]+$ ]]` tests that `$n` is made only of digits.
@@check
ARGS=('' '5' '1 2 3' '10 20 30 40' '3 x 4' 'abc' '7 8.5' '12 -3')
COMPARE="stdout exit errmsg"
extra_check() {
  [[ $REF_CODE == 1 ]] && { [[ $ERR == *sumargs.sh* || $ERR == *sage* || $ERR == *Uso* || $ERR == *uso* ]] || fail "the message should show the correct usage"; }
  [[ $REF_CODE == 2 ]] && { local bad; bad=$(eval "set -- $CASE"; for a in "$@"; do [[ $a =~ ^[0-9]+$ ]] || { echo "$a"; break; }; done); mentions "$bad"; }
}
@@solution
#!/bin/bash
if (( $# == 0 )); then
  echo "Error: no numbers given" >&2
  echo "Usage: $0 number..." >&2
  exit 1
fi
for n in "$@"; do
  if [[ ! $n =~ ^[0-9]+$ ]]; then
    echo "Error: '$n' is not a non-negative integer" >&2
    exit 2
  fi
done
total=0
for n in "$@"; do
  total=$((total + n))
done
echo "Total: $total"
@@step 4 | Count and average
@@readme
Negative integers (`-5`) are now valid numbers. Print three lines, in this order:

```
Count: 3
Total: 10
Average: 3
```

The average is the integer division of the total by the count (`$(( total / count ))` truncates toward zero). Errors work as before (the bad-argument check must now accept an optional minus sign).
@@check
ARGS=('5' '1 2 3' '10 20 30 40' '-5 3' '-7 -8 -9' '3 x 4' '' '1 -' '7 8')
COMPARE="stdout exit errmsg"
extra_check() {
  [[ $REF_CODE == 1 ]] && { [[ $ERR == *sumargs.sh* || $ERR == *sage* || $ERR == *Uso* || $ERR == *uso* ]] || fail "the message should show the correct usage"; }
  [[ $REF_CODE == 2 ]] && { local bad; bad=$(eval "set -- $CASE"; for a in "$@"; do [[ $a =~ ^-?[0-9]+$ ]] || { echo "$a"; break; }; done); mentions "$bad"; }
}
@@solution
#!/bin/bash
if (( $# == 0 )); then
  echo "Error: no numbers given" >&2
  echo "Usage: $0 number..." >&2
  exit 1
fi
for n in "$@"; do
  if [[ ! $n =~ ^-?[0-9]+$ ]]; then
    echo "Error: '$n' is not an integer" >&2
    exit 2
  fi
done
total=0
for n in "$@"; do
  total=$((total + n))
done
echo "Count: $#"
echo "Total: $total"
echo "Average: $((total / $#))"
