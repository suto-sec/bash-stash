@@step 1 | Count the words
@@readme
Write `wordfreq.sh FILE`. A **word** is a maximal run of ASCII letters; everything else (spaces, digits, punctuation, apostrophes, hyphens) separates words, and case is ignored: `Three` and `THREE` are the same word `three`, `it's` is `it` and `s`, `four-five` is `four` and `five`. Print one line `WORD: COUNT` per different word, the **most frequent first**, equal counts in alphabetical order (as `sort` orders text).

`tr -cs 'A-Za-z' '\n'` splits the words, `tr 'A-Z' 'a-z'` lowers them.
@@check
ARGS=('small.txt' 'text.txt' 'empty.txt' '"two words.txt"')
COMPARE="stdout exit"
@@solution
#!/bin/bash
tr -cs 'A-Za-z' '\n' < "$1" | tr 'A-Z' 'a-z' | sort | uniq -c | sort -k1,1nr -k2,2 | while read -r n w; do echo "$w: $n"; done
exit 0
@@step 2 | Only the top N
@@readme
An optional second argument `N` shows only the **first N lines** (the N most frequent words); the default is 5. `N` is assumed to be a valid positive integer in this step.
@@check

#!/bin/bash
top=${2:-5}
tr -cs 'A-Za-z' '\n' < "$1" | tr 'A-Z' 'a-z' | sort | uniq -c | sort -k1,1nr -k2,2 | head -n "$top" | while read -r n w; do echo "$w: $n"; done

@@step 4 | Ignore the short words (-m)
@@readme
`-m LEN` (as the **first two arguments**, before the file) ignores the words with **fewer than LEN letters** (`-m 3` keeps `the` and drops `it` and `a`). `LEN` is a positive integer with the same check as `N` (error with the value, exit **4**); `-m` without a value is the usage error (exit 1). Everything else is as before.

  if [[ $REF_CODE == [234] ]]; then

@@solution
#!/bin/bash
min=1
if [[ $1 == -m ]]; then
  (( $# >= 2 )) || { echo "Error: -m needs a value" >&2; echo "Usage: $0 [-m len] file [n]" >&2; exit 1; }
  min=$2; shift 2
fi
if (( $# < 1 || $# > 2 )); then echo "Error: wrong number of arguments" >&2; echo "Usage: $0 [-m len] file [n]" >&2; exit 1; fi
[[ -e $1 ]] || { echo "Error: $1 does not exist" >&2; exit 2; }
[[ -f $1 ]] || { echo "Error: $1 is not a regular file" >&2; exit 3; }
[[ $min =~ ^[0-9]+$ ]] && (( min >= 1 )) || { echo "Error: $min is not a positive integer" >&2; exit 4; }
top=${2:-5}
[[ $top =~ ^[0-9]+$ ]] && (( top >= 1 )) || { echo "Error: $top is not a positive integer" >&2; exit 4; }
tr -cs 'A-Za-z' '\n' < "$1" | tr 'A-Z' 'a-z' | awk -v m="$min" 'length($0) >= m' | sort | uniq -c | sort -k1,1nr -k2,2 | head -n "$top" | while read -r n w; do echo "$w: $n"; done
exit 0
