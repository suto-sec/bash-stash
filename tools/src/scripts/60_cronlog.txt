@@step 1 | How many jobs ran
@@readme
Cron lines look like `Mar 3 02:00:01 host CRON[412]: (ana) CMD (/usr/bin/backup)`. Write `cronlog.sh LOG`. It prints `Jobs: N`, the number of lines that contain ` CMD (`. Other lines of the log are ignored.
@@check
ARGS=('cron.log' 'calm.log' 'empty.log')
COMPARE="stdout exit"
@@solution
#!/bin/bash
echo "Jobs: $(grep -c ' CMD (' "$1")"
@@step 2 | Per user
@@readme
Before the `Jobs: N` line print `user: N` for every user that ran at least one job (the name between the first parentheses of the line), sorted by user name.

`read -r -a w` and `${w[5]}` is `(ana)`: strip the parentheses with `${w[5]#(}` and `${u%)}`.
@@check
ARGS=('cron.log' 'calm.log' 'empty.log')
COMPARE="stdout exit"
@@solution
#!/bin/bash
declare -A n
while read -r -a w; do
  [[ " ${w[*]} " == *" CMD "* ]] || continue
  u=${w[5]#(}; u=${u%)}
  n[$u]=$(( ${n[$u]:-0} + 1 ))
done < "$1"
for u in $(printf '%s\n' "${!n[@]}" | sort); do echo "$u: ${n[$u]}"; done
echo "Jobs: $(grep -c ' CMD (' "$1")"

@@step 4 | One user
@@readme
`cronlog.sh -u USER LOG` prints only the **commands** that `USER` ran, one per line (what is inside `CMD (...)`, in log order), then `Jobs: N` with the count for that user. `-u` needs a user and the log (otherwise the usage error); the log checks are the same.
@@check

@@solution
#!/bin/bash
user=
if [[ $1 == -u ]]; then
  if (( $# != 3 )); then echo "Error: -u needs a user and a log" >&2; echo "Usage: $0 [-u user] log" >&2; exit 1; fi
  user=$2; shift 2
fi
if (( $# != 1 )); then echo "Error: one log is needed" >&2; echo "Usage: $0 [-u user] log" >&2; exit 1; fi
[[ -f $1 && -r $1 ]] || { echo "Error: cannot read $1" >&2; exit 2; }
if [[ -n $user ]]; then
  n=0
  while read -r -a w; do
    [[ " ${w[*]} " == *" CMD "* ]] || continue
    [[ ${w[5]} == "($user)" ]] || continue
    c=${w[*]:7}; c=${c#(}; c=${c%)}
    echo "$c"; n=$((n + 1))
  done < "$1"
  echo "Jobs: $n"
  exit 0
fi
declare -A n

  [[ " ${w[*]} " == *" CMD "* ]] || continue
  u=${w[5]#(}; u=${u%)}
  n[$u]=$(( ${n[$u]:-0} + 1 ))
done < "$1"
