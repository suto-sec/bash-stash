@@step 1 | Extract into a directory
@@readme
Write `unarchive.sh ARCHIVE DEST`. It extracts the gzip tar archive `ARCHIVE` into the existing directory `DEST` and prints `Extracted N entries`, where N is the number of entries the archive lists (`tar tzf archive | wc -l`: files and directories).

@@step 2 | Create the directory
@@readme
If `DEST` does not exist, create it and print exactly `Directory DEST created` (with `DEST` as it was given) before the `Extracted` line. `DEST` becomes optional: by default it is `extracted` (in the current directory).
@@check

@@solution
#!/bin/bash
dest=${2:-extracted}
if [[ ! -d $dest ]]; then mkdir -p "$dest"; echo "Directory $dest created"; fi
tar xzf "$1" -C "$dest"
echo "Extracted $(tar tzf "$1" | wc -l) entries"

#!/bin/bash
if (( $# < 1 || $# > 2 )); then echo "Error: wrong number of arguments" >&2; echo "Usage: $0 archive [dest]" >&2; exit 1; fi
[[ -f $1 ]] || { echo "Error: $1 is not a regular file" >&2; exit 2; }
case $1 in *.tgz|*.tar.gz) ;; *) echo "Error: $1 is not a .tgz or .tar.gz archive" >&2; exit 3 ;; esac
dest=${2:-extracted}
if [[ -d $dest && -n $(ls -A "$dest") ]]; then echo "Error: $dest is not empty" >&2; exit 4; fi
if [[ ! -d $dest ]]; then mkdir -p "$dest"; echo "Directory $dest created"; fi
tar xzf "$1" -C "$dest"
echo "Extracted $(tar tzf "$1" | wc -l) entries"
