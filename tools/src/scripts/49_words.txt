@@step 1 | Count each line
@@readme
Write `words.sh FILE`. For every line print `line N: W words` (`N` is the line number, `W` the number of words; words are separated by blanks, and a blank line has 0 words). Always the plural, `1 words` too.

`read -r -a w` puts the words of a line into an array: `${#w[@]}` is how many.
@@check
ARGS=('poem.txt' 'empty.txt')
COMPARE="stdout exit"
@@solution
#!/bin/bash
n=0
while read -r -a w; do
  n=$((n + 1))
  echo "line $n: ${#w[@]} words"
done < "$1"
exit 0
@@step 2 | A total
@@readme
Finish with `total: T words`, the sum of all the lines (`total: 0 words` for an empty file).
@@check
ARGS=('poem.txt' 'empty.txt')
COMPARE="stdout exit"
@@solution
#!/bin/bash
n=0 t=0
while read -r -a w; do
  n=$((n + 1)); t=$((t + ${#w[@]}))
  echo "line $n: ${#w[@]} words"
done < "$1"
echo "total: $t words"
