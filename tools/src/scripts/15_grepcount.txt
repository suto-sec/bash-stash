@@step 1 | One file
@@readme
Write `grepcount.sh WORD FILE`. It prints how many lines of `FILE` contain `WORD` (case-sensitive), as `FILE: N`.

`grep -c WORD file` prints the number of matching lines.
@@check
ARGS=('Error a.log' 'info b.log' 'zzz a.log' 'Error empty.log')
COMPARE="stdout exit"
@@solution
#!/bin/bash
echo "$2: $(grep -c -- "$1" "$2")"
@@step 2 | Many files
@@readme
`grepcount.sh WORD FILE...` takes **one or more files** after the word and prints one `FILE: N` line each. With fewer than two arguments (no file): error message **and the correct usage** (e.g. `Usage: grepcount.sh word file...`), exit **1**.
@@check
ARGS=('Error a.log' 'Error a.log b.log' 'info b.log a.log empty.log' '' 'Error')
COMPARE="stdout exit errmsg"
extra_check() { [[ $REF_CODE == 1 ]] && { usage_ok || fail "the message should show the correct usage"; }; }
@@solution
#!/bin/bash
if (( $# < 2 )); then echo "Error: a word and a file are needed" >&2; echo "Usage: $0 word file..." >&2; exit 1; fi
word=$1; shift
for f in "$@"; do
  echo "$f: $(grep -c -- "$word" "$f")"
done
@@step 3 | Skip unreadable files
@@readme
A file that is not a readable regular file prints an error message with its name on standard error, is skipped, and the script ends with exit code **2** after processing the rest.
@@check
ARGS=('Error a.log' 'Error a.log b.log' 'Error nothing.log a.log' 'Error adir b.log' 'Error locked.log a.log' 'Error nothing.log' 'Error')
COMPARE="stdout exit errmsg"
extra_check() { [[ $REF_CODE == 1 ]] && { usage_ok || fail "the message should show the correct usage"; }; }
@@solution
#!/bin/bash
if (( $# < 2 )); then echo "Error: a word and a file are needed" >&2; echo "Usage: $0 word file..." >&2; exit 1; fi
word=$1; shift
bad=0
for f in "$@"; do
  if [[ ! -f $f || ! -r $f ]]; then echo "Error: cannot read $f" >&2; bad=1; continue; fi
  echo "$f: $(grep -c -- "$word" "$f")"
done
(( bad == 0 )) || exit 2
@@step 4 | Ignore case
@@readme
If the **first** argument is `-i`, the search ignores upper/lower case (`grep -i`) and the word and files follow (`grepcount.sh -i error a.log`). Everything else stays the same; `-i` with fewer than two more arguments is the usage error.
@@check
ARGS=('Error a.log' '-i error a.log' '-i error a.log b.log' 'Error nothing.log a.log' '-i error' '-i' '' 'Error locked.log')
COMPARE="stdout exit errmsg"
extra_check() { [[ $REF_CODE == 1 ]] && { usage_ok || fail "the message should show the correct usage"; }; }
@@solution
#!/bin/bash
opt=
if [[ $1 == -i ]]; then opt=-i; shift; fi
if (( $# < 2 )); then echo "Error: a word and a file are needed" >&2; echo "Usage: $0 [-i] word file..." >&2; exit 1; fi
word=$1; shift
bad=0
for f in "$@"; do
  if [[ ! -f $f || ! -r $f ]]; then echo "Error: cannot read $f" >&2; bad=1; continue; fi
  echo "$f: $(grep -c $opt -- "$word" "$f")"
done
(( bad == 0 )) || exit 2
