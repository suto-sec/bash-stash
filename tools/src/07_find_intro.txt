@@topic 07_find | find
@@ex 0752 find_name_intro | Quick refresher: find -name
@@level 1
@@cmds find -name
@@readme
Under `data`, print (one per line, **sorted**) the paths of every file named `notes.txt`
(there may be several, in different subdirectories).

Remember to **quote** the pattern.
@@check
SEEDS=1
setup() { mkdir -p data/{a,b/c}; touch data/notes.txt data/a/notes.txt data/b/c/notes.txt data/a/notes.md data/other.txt; }
@@solution
#!/bin/bash
find data -name 'notes.txt' | sort

@@ex 0754 find_size_intro | Quick refresher: find -size

@@readme
Under `files`, print the regular files **bigger than 1 MiB** (`-size +1M`), one per line, **sorted**.
@@check
SEEDS=1

@@ex 0755 find_mtime_intro | Quick refresher: find -mtime

@@ex 0756 find_exec_intro | Quick refresher: find -exec
@@level 1
@@cmds find -exec {} \;
@@readme
Under `scripts`, add execute permission for the user (`chmod u+x`) to every file ending in `.sh`,
using a single `find ... -exec chmod ...` command. Nothing to print.
@@check
COMPARE="stdout exit files"
SEEDS=1
setup() { mkdir -p scripts/sub; touch scripts/a.sh scripts/b.sh scripts/sub/c.sh scripts/d.txt; }
extra_check() { must_use -exec; }
@@solution
#!/bin/bash
find scripts -type f -name '*.sh' -exec chmod u+x {} +
