@@topic 04_archives | tar, gzip & compression
@@ex 0426 tar_c_intro | tar -c: creating an archive
@@level 1
@@cmds tar -cf
@@readme
`tar` packs several files into one archive file. `-c` creates an archive and `-f NAME` gives the archive's name.

The current directory contains `datos.txt`. Create an (uncompressed) archive called `archivo.tar` that contains it. Nothing is printed.

Hint: `tar -cf ARCHIVE.tar FILE...`
@@check
SEEDS=1
setup() { randtext 3 > datos.txt; }
extra_check() {
  [[ -f $W/archivo.tar ]] || { fail "archivo.tar was not created"; return; }
  tar tf "$W/archivo.tar" 2>/dev/null | grep -qx datos.txt || fail "archivo.tar doesn't contain datos.txt"
}
@@solution
#!/bin/bash
tar -cf archivo.tar datos.txt

@@ex 0427 tar_t_intro | tar -t: listing an archive
@@level 1
@@cmds tar -tf
@@readme
`tar -t` lists the content of an archive without extracting anything.

The file `paquete.tar` exists in the current directory. Print the paths of the files stored inside it, one per line.

Expected output:

```
f1.txt
f2.txt
f3.txt
```

Hint: `tar -tf ARCHIVE.tar` (`t` = list, `f` = the archive's name follows).
@@check
SEEDS=1
setup() { local i; for i in 1 2 3; do randtext 2 > "f$i.txt"; done; tar --sort=name -cf paquete.tar f1.txt f2.txt f3.txt; rm f1.txt f2.txt f3.txt; }
extra_check() { must_use tar; }
@@solution
#!/bin/bash
tar -tf paquete.tar

@@ex 0428 tar_x_intro | tar -x: extracting an archive
@@level 1
@@cmds tar -xf
@@readme
`tar -x` extracts the files stored in an archive, into the current directory.

The file `paquete.tar` exists in the current directory (it contains one file, `dato.txt`). Extract it. Afterwards `dato.txt` must exist. Nothing is printed.

Hint: `tar -xf ARCHIVE.tar` (`x` = extract, `f` = the archive's name follows).
@@check
SEEDS=1
COMPARE="stdout exit files"
setup() { randtext 3 > dato.txt; tar -cf paquete.tar dato.txt; rm dato.txt; }
extra_check() { must_use tar; }
@@solution
#!/bin/bash
tar -xf paquete.tar

@@ex 0429 gzip_intro | gzip: compressing a file
@@level 1
@@cmds gzip
@@readme
`gzip` compresses a file. It **replaces** the original with a compressed one that ends in `.gz`.

Compress `informe.txt` with `gzip`. Afterwards `informe.txt.gz` must exist and `informe.txt` must not. Nothing is printed.

Hint: `gzip file`
@@check
SEEDS=1
COMPARE="stdout exit files"
setup() { randtext 4 > informe.txt; }
extra_check() { must_use gzip; }
@@solution
#!/bin/bash
gzip informe.txt

@@ex 0430 gunzip_intro | gunzip: decompressing a file
@@level 1
@@cmds gunzip
@@readme
`gunzip` decompresses a `.gz` file and gives back the original (without the `.gz`).

The file `datos.csv.gz` exists in the current directory. Decompress it. Afterwards `datos.csv` must exist and `datos.csv.gz` must not. Nothing is printed.

Hint: `gunzip file.gz`
@@check
SEEDS=1
COMPARE="stdout exit files"
setup() { randtext 4 > datos.csv; gzip datos.csv; }
extra_check() { must_use gunzip; }
@@solution
#!/bin/bash
gunzip datos.csv.gz
