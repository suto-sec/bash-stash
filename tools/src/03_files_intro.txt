@@level 1
@@cmds touch
@@readme

Create an empty file named `nuevo.txt` in the current directory. Nothing is printed.

@@ex 0341 rm_intro | rm and rm -r

@@ex 0343 ln_s_intro | ln -s: a symbolic link
@@level 1
@@cmds ln -s, readlink
@@readme
A symbolic link is a small file that stores the path of another file (like a shortcut).

The current directory contains the file `original`.

1. Create a symbolic link called `blando` that points to `original`.
2. Print the path stored inside `blando` with `readlink`.

Expected output:

```
original
```

Hint: `ln -s TARGET LINKNAME`, then `readlink LINKNAME`.
@@check
COMPARE="stdout exit files"
setup() { randtext 2 > original; }
extra_check() { must_use 'ln -s' readlink; }
@@solution
#!/bin/bash
ln -s original blando
readlink blando

@@ex 0344 stat_intro | stat: basic metadata
@@level 1
@@cmds stat -c
@@readme
`stat` shows the information of a file. With `-c FORMAT` you choose what to print: `%s` is the size in bytes.

The current directory contains a file `f`. Print its size in bytes, and nothing else, with `stat -c %s`.

Expected output (the size changes on every run):

```
1234
```

Hint: `stat -c %s file`
@@check
setup() { bigfile f $(randr 1 5000); }
extra_check() { must_use stat; }
@@solution
#!/bin/bash
stat -c %s f

@@ex 0345 basename_dirname_intro | basename and dirname
@@level 1
@@cmds basename, dirname
@@readme
`basename` prints the last part of a path (the file name); `dirname` prints everything before it (the folder).

1. Write this line at the top of your script: `P=/home/alumno/datos/informe.txt`
2. Print the file name of `$P` with `basename`, and then its folder with `dirname`:

```
informe.txt
/home/alumno/datos
```

Hint: `basename "$P"` and `dirname "$P"`
@@check
SEEDS=1
extra_check() { must_use basename dirname; }
@@solution
#!/bin/bash
P=/home/alumno/datos/informe.txt
basename "$P"
dirname "$P"
