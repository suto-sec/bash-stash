@@ex 1442 test_bracket_intro | Quick refresher: test / [ ]
@@level 1
@@cmds test, [ ]
@@readme
`[ -e PATH ]` is true if the path exists (a file or a directory).

The script receives one argument: a path. Print `exists` if that path exists, and `missing` if it does not.

Examples: the checker runs it with `fichero` (a file that exists) and with `noexiste` (nothing with that name).

```
exists
missing
```

Hint:

```
if [ -e "$1" ]; then
  echo ...
else
  echo ...
fi
```
@@check
SEEDS=1
setup() { touch fichero; }
ARGS=('fichero' 'noexiste')
@@solution
#!/bin/bash
if [ -e "$1" ]; then echo exists; else echo missing; fi

@@ex 1443 if_elif_intro | Quick refresher: if / elif / else
@@level 1
@@cmds if, elif, else
@@readme
`if` / `elif` / `else` runs the first block whose condition is true. To compare numbers use `-gt` (greater than), `-lt` (less than) and `-eq` (equal), for example `[ "$1" -gt 0 ]`.

The script receives one whole number. Print `positive` if it is greater than 0, `negative` if it is less than 0 and `zero` otherwise, using an `if` / `elif` / `else` chain.

Examples: `5` prints `positive`, `-3` prints `negative`, `0` prints `zero`.

Hint:

```
if [ "$1" -gt 0 ]; then
  echo ...
elif [ ... ]; then
  echo ...
else
  echo ...
fi
```
@@check
SEEDS=1
ARGS=('5' '-3' '0')
extra_check() { must_use if elif; }
@@solution
#!/bin/bash
if [ "$1" -gt 0 ]; then echo positive
elif [ "$1" -lt 0 ]; then echo negative
else echo zero
fi

@@ex 1444 case_intro | Quick refresher: case
@@level 1
@@cmds case
@@readme
`case` compares a value with several patterns and runs the commands of the first pattern that matches. `|` inside a pattern means "or" and `*` matches anything (use it as the last, default one).

The script receives a day abbreviation: `mon`, `tue`, `wed`, `thu`, `fri`, `sat` or `sun`. Print `weekend` for `sat` and `sun`, and `weekday` for the others, using a `case` statement.

Examples: `mon` prints `weekday`, `sat` prints `weekend`.

Hint:

```
case $1 in
  sat|sun) echo ... ;;
  *) echo ... ;;
esac
```
@@check
SEEDS=1
ARGS=('mon' 'wed' 'fri' 'sat' 'sun')
extra_check() { must_use case; }
@@solution
#!/bin/bash
case $1 in
  sat|sun) echo weekend ;;
  *) echo weekday ;;
esac
