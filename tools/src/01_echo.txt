@@ex 0103 special_chars | Printing special characters
@@level 1
@@cmds echo, quoting, \
@@readme
Print these three lines exactly (the second one must show the **real value** of your `$HOME`):

```
Quiero imprimir el carácter ;
$HOME = /the/value/of/your/home
Precio: 5$ & 10% de descuento (IVA incl.)
```

Hint: `;`, `&`, `(`, `)` and `$` are special for the shell. Use quotes or `\`.
@@check
SEEDS=1
@@solution
#!/bin/bash
echo "Quiero imprimir el carácter ;"
echo "\$HOME = $HOME"
echo 'Precio: 5$ & 10% de descuento (IVA incl.)'

@@ex 0106 single_vs_double | Single vs double quotes
@@level 1
@@cmds echo, ' ", \
@@readme
Print exactly these lines (`<home>` is the real value of `$HOME`):

```
Single quotes print '$HOME' literally
Double quotes expand "$HOME" to <home>
A backslash: \ and a double quote: "
```

Notice that the first line contains the characters `'$HOME'` including the single quotes.
@@check
SEEDS=1
@@solution
#!/bin/bash
echo "Single quotes print '\$HOME' literally"
echo "Double quotes expand \"\$HOME\" to $HOME"
echo 'A backslash: \ and a double quote: "'

@@ex 0108 var_braces | Variables and ${...}
@@level 2
@@cmds variables, ${VAR}, cat
@@readme
The file `name.txt` (in the current directory) contains a single word, e.g. `kernel`.

1. Store its content in a variable called `NAME`.
2. Print `NAME_backup.tar`, e.g. `kernel_backup.tar`
3. Print `NAMEs are cool`, e.g. `kernels are cool`

```
kernel_backup.tar
kernels are cool
```

Hint: `$NAME_backup` is a different (empty) variable. Use `${NAME}`.
@@check
setup() { word > name.txt; }
@@solution
#!/bin/bash
NAME=$(cat name.txt)
echo "${NAME}_backup.tar"
echo "${NAME}s are cool"

```
user<TAB>uid

alumno<TAB>1000

```
@@check

extra_check() { (( $(ans_code | grep -o 'echo' | wc -l) == 2 )) || fail "use exactly two echo commands"; }

@@ex 0110 date_host | date formats and $HOSTNAME
@@level 2
@@cmds date, $HOSTNAME
@@readme
Print the machine name and the current date/time in these formats (see `man date`):

```
Host: labhost
Date: 2026-06-20
Year: 2026, day of year: 171
```

Use `$HOSTNAME` and `date +FORMAT`.
@@check
SEEDS=1
@@solution
#!/bin/bash
echo "Host: $HOSTNAME"
echo "Date: $(date +%Y-%m-%d)"
echo "Year: $(date +%Y), day of year: $(date +%j)"

@@ex 0112 quoting_spaces | Quoting preserves spaces
@@level 2
@@cmds quoting, variables
@@readme
The file `msg.txt` contains one line with words separated by **several** spaces
(e.g. `hello     big    world`).

Print the line twice: first **exactly as it is** (spaces preserved), then with the words
separated by a **single** space. Read it into a variable with `MSG=$(cat msg.txt)` and play with quotes.

```
hello     big    world
hello big world
```
@@check
setup() { printf '%s   %s %s      %s\n' "$(word)" "$(word)" "$(word)" "$(word)" > msg.txt; }
@@solution
#!/bin/bash
MSG=$(cat msg.txt)

echo $MSG
