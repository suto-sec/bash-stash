@@about
Ten single-choice questions on the basics: job numbers, systemd targets, appending, env and printenv, grep options, crontab, wc, shift, ls -d and what a shell is.

@@q single | Bringing a job back
@@topic jobs-procs
`jobs` shows two stopped jobs, `[1]` and `[2]`. Which command brings job number 2 to the foreground?
(+) `fg %2` :: `%2` names job number 2, and `fg` makes it the foreground job again.
(-) `bg %2` :: It resumes job 2, but in the background.
(-) `jobs %2` :: It only lists the job; it does not change its state.
(-) `kill %2` :: It sends `SIGTERM` to job 2, which ends it.

@@q single | The default target
@@topic boot-systemd
What does `systemctl get-default` print?
(+) The name of the target that the system reaches by default at boot, such as `graphical.target` or `multi-user.target`. :: A target groups units, as the old runlevels did.
(-) The number of the default runlevel, from 0 to 6. :: `systemd` uses named targets; the numbers survive only as aliases.
(-) The kernel that GRUB loads by default. :: That is a GRUB setting, not a systemd one.
(-) The list of the units that failed during the last boot. :: Failed units are listed with `systemctl --failed`.

@@q single | Appending to a missing file
@@topic redirection-pipes
`log.txt` does not exist. What does `echo hi >> log.txt` do?
(+) It creates `log.txt` with the line `hi`. :: `>>` appends and creates the file when it is missing.
(-) It fails with "No such file or directory". :: Redirections create the file; they do not need it to exist.
(-) It does nothing, because there is no content to append to. :: There is always something to append to: an empty file is created first.
(-) It creates `log.txt` empty and prints `hi` on the screen. :: The output of `echo` goes into the file, not to the screen.

@@q single | Variables that children see
@@topic expansion-vars
After `x=1; export y=2`, which statement about `printenv` is FALSE?
(-) `printenv y` prints `2`. :: True: `y` is exported, so it is in the environment.
(-) `env` lists the exported variables, `y` among them. :: True: `env` prints the environment of the shell.
(-) A program started from this shell can read `y`. :: True: exported variables are inherited by the child processes.
(+) `printenv x` prints `1`, because every variable of the shell is shown by `printenv`. :: False: `x` was not exported, so it is not part of the environment and `printenv x` prints nothing.

@@q single | The options of grep
@@topic grep-regex
Which statement about the options of `grep` is FALSE?
(-) `grep -i` ignores the difference between upper and lower case. :: True.
(-) `grep -v` prints the lines that do not match. :: True: it inverts the selection.
(-) `grep -n` puts the line number in front of every line it prints. :: True.
(+) `grep -c` prints the matching lines and, at the end, how many there were. :: False: `-c` prints only the number of matching lines, not the lines themselves.

@@q single | Listing the crontab
@@topic logs-cron
What does `crontab -l` do?
(+) It lists the scheduled jobs in the crontab of the current user. :: `-e` edits it and `-r` removes it.
(-) It opens the crontab of the current user in an editor. :: That is `crontab -e`.
(-) It deletes all the jobs of the current user. :: That is `crontab -r`.
(-) It lists the jobs of all the users of the system. :: Each user has a separate crontab; `-l` shows only your own.

@@q single | Counting with wc
@@topic filters
Which statement about `wc` is TRUE?
(+) `wc -m` counts characters and `wc -c` counts bytes. :: For the line `é` the output of `wc -c` is 3 (two bytes plus the newline) and that of `wc -m` is 2.
(-) `wc -l` counts the words and `wc -w` counts the lines. :: `-l` counts lines; words are counted with `-w`.
(-) `wc -w` counts the lines. :: `-w` counts words.
(-) `wc` with no option prints only the number of lines. :: It prints lines, words and bytes, in that order.

@@q single | The shift command
@@topic scripts
What does `shift` do in a script?
(+) It discards `$1` and moves the rest down: `$2` becomes `$1`. :: It is used to process the arguments one by one in a loop.
(-) It moves the cursor to the next line of the script. :: `shift` is not about the script text.
(-) It shifts the content of a variable one character to the left, dropping the first. :: It works on the positional parameters, not on strings.
(-) It adds the first argument to the end of the list. :: The first argument is discarded, not rotated.

@@q single | Listing a directory itself
@@topic files-fs
`dd` is a directory with a file inside. What does `ls -ld dd` print?
(+) One line in long format that describes the directory `dd` itself. :: `-d` lists the directory instead of its content.
(-) The long listing of the files inside `dd`. :: That is `ls -l dd`.
(-) The inode number of `dd`. :: That is `ls -i`.
(-) The files inside `dd` and all its subdirectories. :: That is `ls -R dd`.

@@q single | What a shell is
@@topic shell-help
What is the shell, in an operating system like Linux? Choose the TRUE statement.
(+) It is a program that reads the lines you type, interprets them and runs the commands. :: It is a normal program that runs on top of the kernel; bash is one of several shells.
(-) It is the part of the kernel that manages the files. :: The shell is an ordinary user-space program, not part of the kernel.
(-) It is the only program that can start other programs. :: Any program can start other programs; the shell does it for the user.
(-) It is the program that the firmware starts first when the computer is switched on. :: The firmware starts a boot loader, which loads the kernel; the shell comes much later.
