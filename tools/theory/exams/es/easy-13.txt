@@exam easy-13 | Examen fácil 13
@@about
Diez preguntas de respuesta única sobre lo básico: acciones de find, alias, agrupar mandatos, expresiones regulares sobre una lista de palabras, initrd, mayúsculas y minúsculas, trabajos en primer plano, estados de salida, borrar ficheros y read.

@@q single | Las acciones de find
¿Qué afirmación sobre las acciones de `find` es FALSA?
(-) `find . -name '*.tmp' -exec rm {} \;` ejecuta `rm` una vez por cada fichero encontrado. :: Cierto: `{}` se sustituye por el nombre de cada fichero.
(-) `find . -name '*.log' -exec ls -l {} +` pasa muchos nombres de fichero a un único `ls`. :: Cierto: con `+` los nombres se agrupan, como hace `xargs`.
(-) `find . -name '*.tmp' -delete` elimina todos los ficheros que coinciden. :: Cierto.
(+) `find . -name '*.tmp' -delete` pide confirmación antes de eliminar cada fichero. :: Falso: `-delete` elimina al instante, sin preguntar; la acción que pregunta es `-ok`.

@@q single | Qué hace un alias
Tras escribir `alias hi='echo hello'` en una shell interactiva, ¿qué imprime `hi world`?
(+) `hello world` :: La shell sustituye la palabra `hi` por `echo hello` y conserva el resto de la línea.
(-) `hi: command not found` :: La shell conoce el alias, así que `hi` se sustituye antes de buscar un mandato.
(-) `world` :: Solo se sustituye el nombre del alias; los argumentos se quedan en la línea y `echo` los imprime.
(-) `hello` :: Los argumentos escritos tras el alias no se pierden: se añaden a la expansión.

@@q single | Una redirección para dos mandatos
¿Qué mandato escribe la salida de `echo one` y de `echo two` en el fichero `out.txt`?
(+) `{ echo one; echo two; } > out.txt` :: Las llaves agrupan los mandatos y la redirección se aplica a la salida de todo el grupo.
(-) `echo one; echo two > out.txt` :: Solo se redirige `echo two`; `one` va a la pantalla.
(-) `echo one | echo two > out.txt` :: `echo` ignora su entrada: el fichero contiene solo `two`.
(-) `echo one && echo two > out.txt` :: La redirección sigue afectando solo al segundo mandato.

@@q single | Coincidir con palabras
En una lista de palabras en inglés, ¿qué afirmación sobre `grep '^c.t$' words` es CIERTA?
(+) Imprime las palabras de tres letras que empiezan por `c` y terminan en `t`, como `cat` o `cut`. :: `^` y `$` fijan el principio y el final de la línea, y el punto representa exactamente un carácter.
(-) Imprime las palabras que contienen el texto `c.t` con un punto de verdad. :: Para buscar un punto literal hay que escribir `\.`.
(-) Imprime toda palabra que empiece por `c` o termine en `t`. :: El patrón exige las dos condiciones y exactamente una letra entre ellas.
(-) Imprime palabras de cualquier longitud que empiezan por `c` y terminan en `t`, como `cart`. :: El punto coincide con un carácter, así que `cart` (dos letras entre `c` y `t`) no coincide.

@@q single | Mensajes del núcleo en el arranque
¿Qué mandato muestra los mensajes que imprimió el núcleo mientras el sistema arrancaba?
(+) `dmesg` :: Imprime el búfer circular del núcleo: detección de hardware, controladores cargados, montaje del sistema de ficheros raíz...
(-) `last` :: Lista los inicios de sesión pasados de los usuarios, leídos de `/var/log/wtmp`.
(-) `history` :: Lista los mandatos escritos en la shell actual.
(-) `uname -a` :: Imprime el nombre y la versión del núcleo, no los mensajes que escribió.

@@q single | Nombres en cualquier caso
Linux trata `Notes.TXT` y `notes.txt` como ficheros distintos. ¿Qué mandato lista los dos?
(+) `find . -iname notes.txt` :: `-iname` ignora la diferencia entre mayúsculas y minúsculas en el nombre.
(-) `find . -name notes.txt` :: `-name` distingue mayúsculas y minúsculas: encuentra solo `notes.txt`.
(-) `find . -name 'notes.TXT'` :: Encuentra solo el fichero con exactamente esa grafía.
(-) `find . -name notes.txt -i` :: `-i` no es una opción de `find`; falla con «unknown predicate».

@@q single | Trabajos en primer plano
¿Qué afirmación define un trabajo en primer plano?
(+) El trabajo que tiene el terminal: la shell lo espera antes del siguiente prompt. :: Solo un trabajo a la vez puede estar en primer plano; `Ctrl+C` y `Ctrl+Z` actúan sobre él.
(-) Un trabajo que se ejecuta con mayor prioridad que los demás. :: Primer y segundo plano no dicen nada sobre la prioridad.
(-) Un trabajo que no tiene terminal y se lanza en el arranque. :: Eso describe un demonio.
(-) Un trabajo que sigue ejecutándose cuando el usuario cierra la sesión. :: Para eso sirve `nohup`.

@@q single | El operador ||
En `cmd1 || cmd2`, ¿cuándo se ejecuta `cmd2`?
(+) Solo cuando `cmd1` falla, es decir, termina con un estado distinto de 0. :: `||` significa «o si no»: el segundo mandato es una alternativa.
(-) Solo cuando `cmd1` tiene éxito. :: Eso es lo que hace `&&`.
(-) Siempre, después de que `cmd1` haya terminado. :: Eso es lo que hace `;`.
(-) A la vez que `cmd1`, en segundo plano. :: Ejecutar a la vez es lo que hace `&` o una tubería.

@@q single | Borrar necesita el directorio
¿Qué afirmación sobre borrar el fichero `docs/old.txt` es FALSA?
(-) Para borrarlo necesitas permiso de escritura y de ejecución sobre el directorio `docs`. :: Cierto: borrar modifica el directorio, que es el que lista los nombres.
(-) Un fichero con modo `r--r--r--` se puede borrar si tienes permiso de escritura sobre su directorio. :: Cierto: no se consultan los permisos del fichero.
(-) Si `docs` tiene modo `r-xr-xr-x` no puedes borrar el fichero, aunque seas su propietario. :: Cierto: nadie tiene permiso de escritura sobre el directorio.
(+) Solo puedes borrarlo si tienes permiso de escritura sobre el propio fichero. :: Falso: el permiso que importa es el del directorio que contiene el nombre.

@@q single | El mandato read
¿Qué hace `read -p "Name: " n` en un script?
(+) Imprime el prompt `Name: ` y guarda la línea escrita en la variable `n`. :: `-p` da el texto del prompt y la primera palabra tras las opciones es la variable que recibe la entrada.
(-) Lee en la variable `n` el contenido de un fichero llamado `Name: `. :: `read` lee la entrada estándar, no un fichero nombrado con `-p`.
(-) Imprime `Name: ` y el valor de `n`. :: No imprime la variable; la asigna.
(-) Redirige a `n` la salida del mandato anterior. :: `-p` no tiene nada que ver con las tuberías.
