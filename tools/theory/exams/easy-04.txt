@@q single | Find regular files by name
@@topic find
Which command lists the regular files whose name ends in `.conf` under `/etc`?
(-) `find -name "*.conf" /etc` :: The starting directory must come before the tests: `find` complains "paths must precede expression".
(-) `find /etc -type d -name "*.conf"` :: `-type d` selects directories, not regular files.
(+) `find /etc -type f -name "*.conf"` :: `-type f` keeps regular files and the quoted pattern is matched by `find` itself.
(-) `find /etc -f -name "*.conf"` :: `-f` is not a test of `find`; the type of file is selected with `-type`.

@@q single | Numeric order
@@topic filters
The file `nums` contains the lines `9`, `10` and `100`. Which command prints them in the order `9`, `10`, `100`?
(-) `sort nums` :: Alphabetical order compares character by character: `10`, `100`, `9`.
(+) `sort -n nums` :: `-n` compares the lines as numbers.
(-) `sort -r nums` :: `-r` reverses the alphabetical order: `9`, `100`, `10`.
(-) `sort -u nums` :: `-u` removes duplicate lines but the order stays alphabetical: `10`, `100`, `9`.

@@q single | Removing write permission
@@topic permissions
What does `chmod go-w report.txt` do?
(-) It gives write permission to the group and to the others. :: `-` removes permissions; `+` would add them.
(-) It removes write permission from the owner and from the group. :: `g` and `o` are group and others; the owner is `u`.
(+) It removes write permission from the group and from the others. :: `go` selects those two classes, `-` removes and `w` is the write permission.
(-) It sets the permissions of the group and the others to exactly write only. :: Setting an exact value would use `=`.

@@q single | Job control
@@topic jobs-procs
You started `sort bigfile` and suspended it with Ctrl+Z; `jobs` shows it as job number 1. Which statement is TRUE?
(-) `fg` suspends the job again if it is running in the background. :: `fg` brings a job to the foreground; it never suspends it.
(-) The job number 1 is the PID of the process. :: The job number is a counter of the current shell, the PID is assigned by the system.
(+) `bg %1` resumes it and leaves it running in the background. :: `bg` resumes a suspended job without waiting for it.
(-) `jobs` lists all the processes of all the users of the system. :: `jobs` shows only the jobs of the current shell session.

@@q single | Commands that ignore stdin
@@topic redirection-pipes
Which statement about input redirection with `<` is FALSE?
(-) `wc -l < names.txt` prints only the number of lines, without the file name. :: True: `wc` reads stdin and does not know a file name.
(-) `sort < names.txt` gives the same lines as `sort names.txt`. :: True: both read the file, one through stdin and the other by name.
(+) `ls < docs` lists the contents of the directory `docs`. :: False: `ls` does not read stdin, so it lists the current directory and `docs` is ignored.
(-) `cat < names.txt` shows the file because `cat` reads stdin when it gets no file name. :: True: with no arguments `cat` reads its standard input.

@@q single | Deleting with rm
@@topic files-fs
Which statement about `rm` is FALSE?
(-) `rm notes` on a directory called `notes` fails with "Is a directory". :: True: directories need `-r`.
(-) `rm -r project` deletes the directory `project` and everything inside it. :: True: `-r` is recursive.
(+) `rm -f report.txt` asks for confirmation before deleting. :: False: `-f` forces the deletion without asking; the option that asks is `-i`.
(-) `rm -i report.txt` asks before deleting the file. :: True: `-i` is interactive, useful for root.

@@q single | A sudoers line
@@topic users-sessions
`/etc/sudoers` contains the line `%staff ALL=(ALL) ALL`. Which statement is TRUE?
(-) It defines a user whose name is `%staff`. :: The `%` marks a group name, not a user.
(+) Every member of the group `staff` may run any command as any user. :: The `%` prefix selects a group; `ALL` in each field means any host, any target user and any command.
(-) Only the user `root` may use `sudo`, and `staff` is the machine name. :: The first field is who may use `sudo`; here it is a group, not a machine.
(-) Members of `staff` become root only after typing the password of root. :: `sudo` asks for the password of the user who runs it; knowing root's password is not needed.

@@q single | grep counting
@@topic grep-regex
`animals` has four lines: `cat`, `Dog`, `dog food` and `bird`. What does `grep -ci dog animals` print?
(-) `1` :: That is the result without `-i`: only `dog food` has a lower case `dog`.
(+) `2` :: `-i` ignores case, so `Dog` and `dog food` match, and `-c` prints how many lines matched.
(-) `3` :: That would be the lines that do not contain `dog` with `grep -vc`, which is a different option.
(-) `4` :: That is the total number of lines in the file, not the number that match.

@@q single | Name, count and first argument
@@topic scripts
`show.sh` has execute permission and contains `echo "$0 has $# args, first is $1"`. What does `./show.sh red green` print?
(-) `show.sh has 2 args, first is red` :: `$0` is the name used to call the script, so it includes the `./`.
(-) `./show.sh has 3 args, first is ./show.sh` :: `$#` does not count `$0`, and `$1` is the first argument, not the script.
(+) `./show.sh has 2 args, first is red` :: `$0` is the command as typed, `$#` counts the two arguments and `$1` is the first.
(-) `./show.sh has 2 args, first is green` :: Arguments are numbered from the left: `$1` is `red`.

@@q single | Exported and plain variables
@@topic expansion-vars
You run `COLOR=blue` and then `export SIZE=big`. What does `bash -c 'echo "[$COLOR] [$SIZE]"'` print?
(-) `[blue] [big]` :: Only exported variables reach the new process; `COLOR` was not exported.
(-) `[blue] []` :: It is the other way round: `SIZE` was exported and `COLOR` was not.
(+) `[] [big]` :: `bash -c` starts a child process, which inherits `SIZE` but not `COLOR`.
(-) `[] []` :: `export` exists precisely to pass a variable on to the child processes.
