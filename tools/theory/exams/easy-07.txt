@@q single | find and permissions
@@topic find
What does `find . -type f -perm 644` list?
(-) The files that have at least the permissions `rw-r--r--`, even if they also have more. :: That is `-perm -644`, with a minus sign before the mode.
(-) The files that have any one of the permissions `rw-r--r--`. :: That is `-perm /644`, with a slash before the mode.
(+) The regular files whose permissions are exactly `rw-r--r--`. :: A mode without a prefix must match exactly.
(-) The regular files owned by the user called `644`. :: The owner is selected with `-user`; `-perm` compares the permission bits.

@@q single | Numeric tests
@@topic scripts
Which statement about `test` and `[ ]` is FALSE?
(-) `[ 4 -le 4 ]` succeeds, with exit status 0, as 4 equals 4. :: True: 4 is less than or equal to 4.
(-) `[ 3 -ne 5 ]` succeeds, with exit status 0, as they differ. :: True: 3 and 5 are different.
(-) `[ 2 -gt 9 ]` fails, with exit status 1, as 2 is smaller. :: True: 2 is not greater than 9.
(+) `[ 10 -lt 9 ]` succeeds, since `10` sorts before `9`. :: False: `-lt` compares numbers, and 10 is not smaller than 9, so the status is 1.

@@q single | Character classes
@@topic grep-regex
Which line is matched by `grep 'b[^ae]g'`?
(-) `bag` :: The class `[^ae]` excludes `a` and `e`.
(-) `beg` :: The class `[^ae]` excludes `e` too.
(+) `bug` :: `u` is one character that is neither `a` nor `e`.
(-) `bg` :: The class needs one character between `b` and `g`; here there is none.

@@q single | The end of a log
@@topic logs-cron
Which command shows the last 20 lines of `/var/log/syslog`?
(-) `head -n 20 /var/log/syslog` :: `head` shows the first lines, not the last ones.
(-) `tail -n+20 /var/log/syslog` :: That prints from line 20 to the end, however many lines that is.
(-) `grep -c 20 /var/log/syslog` :: It counts the lines that contain the text `20`.
(+) `tail -n 20 /var/log/syslog` :: `tail -n N` prints the last N lines, which is where the newest entries are.

@@q single | sed
@@topic filters
Which statement about `sed` is FALSE?
(-) `sed 's/-/+/g'` replaces all the dashes of every line. :: True: the `g` flag means every occurrence in the line.
(-) Without the `g` flag, `s/-/+/` replaces only the first dash of each line. :: True.
(-) `sed '/x/d'` prints the input without the lines that contain `x`. :: True: `d` deletes the selected lines.
(+) `sed 's/-/+/' file` changes the content of `file` itself. :: False: it prints the result on stdout and leaves the file as it was; changing the file needs `-i`.

@@q single | Default permissions of new files
@@topic permissions
Which command makes the new regular files created by the shell have the mode `rw-r-----` (640)?
(-) `umask 022` :: It leaves new files as `rw-r--r--` (644).
(-) `umask 640` :: The mask says what is removed: this one gives `-----w-rw-`.
(+) `umask 027` :: It removes nothing from the owner, `w` from the group and everything from the others: 666 becomes 640.
(-) `umask 777` :: It removes every permission: new files would have mode 000.

@@q single | Who expands the wildcards
@@topic expansion-vars
Which statement about `ls *.txt` is TRUE?
(-) `ls` receives the text `*.txt` and searches for the matching files by itself. :: The shell expands the pattern before `ls` starts.
(+) The shell replaces `*.txt` with the names of the matching files and passes them to `ls`. :: That is why `echo *.txt` shows the list of names.
(-) In this pattern `*` matches exactly one character. :: `*` matches any number of characters, including none; `?` is the one for exactly one.
(-) The pattern `[!ab]*` matches names that start with `a` or `b`. :: `[!ab]` is the opposite: a character that is not `a` or `b`.

@@q single | Optional letters
@@topic grep-regex
`words` contains the lines `color`, `colour` and `colr`. What does `grep -E 'colou?r' words` print?
(-) Only `colour`. :: The `u` is optional, so `color` matches as well.
(-) Only `color`. :: `colour`, with the `u`, matches too.
(-) The three lines. :: `colr` has no `o` followed by `r`, so it does not match.
(+) `color` and `colour` :: `?` means zero or one occurrence of the preceding character.

@@q single | The null device
@@topic redirection-pipes
Which statement about `/dev/null` is TRUE?
(-) `command > /dev/null` also hides the error messages of the command. :: It discards stdout only; the errors need `2> /dev/null`.
(+) Everything that is written to it is discarded. :: It is the "black hole" used to throw away output that is not wanted.
(-) It is a directory where deleted files are kept until they are removed for good. :: It is a special file, not a trash directory.
(-) What is written to it can be read later with `cat /dev/null`. :: Reading it gives nothing: it stores no data.

@@q single | Daemons
@@topic jobs-procs
Which kind of process is a daemon?
(-) An interactive process, because it is tied to the shell of a user. :: Interactive processes belong to a shell, running in the foreground or background.
(-) A batch process: it runs once, at the time it was scheduled. :: Batch processes are planned for a given moment, like scripts launched on a schedule.
(+) A background process that does a task of the system, such as a service. :: Daemons work in the background for the system without being tied to a user's terminal.
(-) A process that was suspended with Ctrl+Z. :: That is a stopped job of a shell, not a daemon.
