Ten single-choice questions that combine two facts or ask you to trace two or three steps: file viewers, alternations, file ages, links that survive, zombies and wildcards.

@@q single | Showing files
@@topic filters
Which statement about `cat`, `tac` and `nl` is FALSE?
(-) `cat a b` prints the content of `a` followed by the content of `b`. :: True: `cat` concatenates.
(-) `cat -n f` numbers every line of `f`, the blank ones included. :: True: `-n` numbers all the lines.
(-) By default `nl f` leaves the blank lines without a number. :: True: `nl` numbers only the lines that have text unless it is told otherwise.
(+) `tac f` prints each line written backwards, character by character. :: False: `tac` reverses the order of the lines, last line first; the lines themselves are not changed.

@@q single | cat or dog
@@topic grep-regex
`names` has the lines `cat`, `dog`, `catdog`, `the cat dog` and `bird`. Which command prints the first four lines, the ones that contain `cat` or `dog`?
(-) `grep 'cat|dog' names` :: In a basic regular expression the `|` is an ordinary character: only a line with the text `cat|dog` would match.
(-) `grep -E 'cat dog' names` :: It needs `cat`, a space and `dog` together: only the line `the cat dog` matches.
(-) `grep -E '(cat)(dog)' names` :: Two groups one after the other mean `catdog`: only that line matches.
(+) `grep -E 'cat|dog' names` :: With `-E` the `|` separates alternatives, so a line matches if it contains either word.

@@q single | Numbers or text
@@topic scripts
`a=5` and `b=05`. Which statement is TRUE?
(-) Both `[ $a -eq $b ]` and `[ "$a" = "$b" ]` succeed, because the two variables have the same value. :: They are the same number, but not the same text.
(-) Both `[ $a -eq $b ]` and `[ "$a" = "$b" ]` fail, because `05` is not a valid number. :: A leading zero is accepted: it is read as the number 5.
(-) `[ "$a" = "$b" ]` succeeds and `[ $a -eq $b ]` fails. :: It is the other way round.
(+) `[ $a -eq $b ]` succeeds and `[ "$a" = "$b" ]` fails. :: `-eq` compares numbers (5 and 5); `=` compares the strings `5` and `05`, which differ.

@@q single | Age of files
@@topic find
In an empty directory, `a`, `b` and `c` were last modified 1, 5 and 10 days ago. What does `find . -type f -mtime +3` print?
(-) `./a` :: The file `a` was modified 1 day ago, so it is not older than 3 days.
(-) `./c` :: `+3` means more than 3 days, so `b` (5 days) is included too.
(+) `./b` and `./c` :: `-mtime +3` selects the files modified more than 3 days ago.
(-) `./a`, `./b` and `./c` :: `a` is only one day old and does not pass the test.

@@q single | What survives rm
@@topic files-fs
`orig` contains `x`. You run `ln orig h`, `ln -s orig s`, `cp orig c` and then `rm orig`. Which statement is TRUE?
(-) `cat h` and `cat s` both print `x`, because both are links to `orig`. :: A symbolic link stores the path `orig`, which no longer exists.
(-) Only `cat h` prints `x`, because `c` is just a copy of the name. :: `cp` makes an independent file with its own content, so `c` also keeps `x`.
(+) `cat h` and `cat c` print `x`, while `cat s` fails with "No such file or directory". :: The hard link keeps the inode alive, the copy is a separate file, and the symbolic link points to a name that has gone.
(-) `cat s` and `cat c` print `x`, while `cat h` fails. :: `h` shares the inode of `orig`, and `rm` only removes one name.

@@q single | Changing the owner
@@topic permissions
`ana` (not root) owns `g`. She runs `chmod 600 g; chown root g; chmod 644 g`. What is the result?
(-) All three work and the file ends owned by root with mode `rw-r--r--`. :: A normal user cannot give a file away.
(-) `chmod 600 g` works, but then the other two fail because the file belongs to root. :: `chown root g` is the one that fails, so the file still belongs to ana.
(+) `chown root g` fails ("Operation not permitted"); the file stays ana's, with mode `rw-r--r--`. :: Only root can change the owner; the owner can change the mode, so both `chmod` commands work.
(-) `chmod 600 g` fails, because only root may change modes. :: The owner of a file may change its mode.

@@q single | The Z in ps
@@topic jobs-procs
In the output of `ps aux` a process has the state `Z`. Which statement is TRUE?
(-) It is running and using the CPU at this moment. :: That would be `R`.
(-) It is waiting for a device and cannot be interrupted, and `kill -9` will remove it. :: That is the state `D`, and a zombie ignores `kill` anyway.
(+) It has finished, but its parent has not yet collected its exit status. :: This is a zombie: the process is gone, only its entry in the process table remains.
(-) It is sleeping until some event happens, such as a key press. :: That is `S`.

@@q single | Discarding the errors only
@@topic redirection-pipes
`/etc/hostname` exists and `/nope` does not. What does `ls /nope /etc/hostname 2> /dev/null; echo $?` print?
(-) `/etc/hostname` and then `0` :: `ls` still exits with an error status: the missing file was reported, even if the message was discarded.
(+) `/etc/hostname` and then `2` :: The error message went to `/dev/null`, but the exit status of `ls` is 2.
(-) The error message, `/etc/hostname` and then `2` :: The error message was redirected, so it does not appear.
(-) Only `2` :: The listing of `/etc/hostname` is stdout, which was not redirected.

@@q single | Membership of a group
@@topic users-sessions
`/etc/group` has the lines `dev:x:1005:ana,luis` and `ops:x:1006:`, and `/etc/passwd` has `eva:x:2001:1006:Eva Gil:/home/eva:/bin/bash`. Which statement is FALSE?
(-) `ana` is a member of the group `dev`, as her name is in its list. :: True: her name is in the list of members.
(-) The GID of the group `dev` is 1005, the third field of its line. :: True: the third field is the GID.
(-) Every user of the system is allowed to read the file `/etc/group`. :: True: it is a plain file accessible to everybody (unlike `/etc/shadow`).
(+) `eva` is not in `ops`, as its member list is empty. :: False: her primary group in `/etc/passwd` is 1006, which is `ops`; primary members are not listed in `/etc/group`.

@@q single | Choosing a pattern
@@topic expansion-vars
The directory holds `a1.txt`, `a2.txt`, `a10.txt`, `b1.txt`, `A1.txt` and `notes`. Which command lists exactly `a1.txt` and `a2.txt`?
(-) `ls a*.txt` :: `*` also matches `10`: it lists `a10.txt`, `a1.txt` and `a2.txt`.
(-) `ls ?1.txt` :: Any single character followed by `1.txt`: `a1.txt`, `A1.txt` and `b1.txt`.
(-) `ls [ab]?.txt` :: It also matches `b1.txt`.
(+) `ls a?.txt` :: `a`, exactly one character, then `.txt`: `a1.txt` and `a2.txt`.
