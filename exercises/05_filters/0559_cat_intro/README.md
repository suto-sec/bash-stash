# 0559 · cat: printing a file

**Topic:** Filters: wc, head, tail, cut, sort, uniq, tr, sed, tee... · **Difficulty:** ★☆☆☆☆ · **Commands:** cat

`cat` prints the content of a file.

Print the content of `nota.txt`, exactly as it is.

Example: if `nota.txt` contains

```
hola mundo
adios mundo
```

the output is the same two lines.

Hint: `cat file`
