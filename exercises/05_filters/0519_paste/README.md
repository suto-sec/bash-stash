# 0519 · Joining files side by side

**Topic:** Filters: wc, head, tail, cut, sort, uniq, tr, sed, tee... · **Difficulty:** ★★☆☆☆ · **Commands:** paste, paste -d, paste -s

`nombres.txt` and `edades.txt` have the same number of lines. Print:

1. both files side by side separated by TAB (`paste`)
2. `---`
3. both side by side separated by `,`
4. `---`
5. all the names in **one line** separated by `+` (`paste -s -d`)
