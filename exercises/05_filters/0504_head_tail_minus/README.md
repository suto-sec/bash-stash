# 0504 · All but the first / last N lines

**Topic:** Filters: wc, head, tail, cut, sort, uniq, tr, sed, tee... · **Difficulty:** ★★☆☆☆ · **Commands:** head -n -N, tail -n +N

For the file `datos.txt`, print separated by a line `---`:

1. all the lines **except the last 5**
2. all the lines **except the first 5** (i.e. from line 6 to the end)
3. the last 20 **bytes**
