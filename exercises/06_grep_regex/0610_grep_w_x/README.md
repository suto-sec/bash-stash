# 0610 · Whole words and whole lines

**Topic:** grep & regular expressions · **Difficulty:** ★★☆☆☆ · **Commands:** grep -w, grep -x

For `palabras.txt`, print separated by `---`:

1. lines containing `log` as a **whole word** (not `login`, `blog`...)
2. lines that are **exactly** `log` (whole line)
3. the number of lines that contain `log` anywhere
