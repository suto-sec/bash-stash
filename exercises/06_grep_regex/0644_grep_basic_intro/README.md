# 0644 · grep: lines containing a string

**Topic:** grep & regular expressions · **Difficulty:** ★☆☆☆☆ · **Commands:** grep

`grep text file` prints the lines of the file that contain `text`.

Print the lines of `colores.txt` that contain `rojo`.

Example: if `colores.txt` contains

```
rojo manzana
azul mar
rojo tomate
```

the output is

```
rojo manzana
rojo tomate
```

Hint: `grep rojo file`
