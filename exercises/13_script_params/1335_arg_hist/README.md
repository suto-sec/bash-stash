# 1335 · Counting how many times each argument appears

**Topic:** Script parameters & exit codes · **Difficulty:** ★★★☆☆ · **Commands:** for, arrays, sort

The script receives words as arguments (some may repeat, in any order). For every **distinct** word,
sorted **alphabetically**, print `WORD: N` (N = how many times it appears among the arguments).
Finally print `total: T argumentos, D distintos`. With no arguments, print only
`total: 0 argumentos, 0 distintos`.
