# 0230 · ls: -a and -l

**Topic:** Directories & navigation · **Difficulty:** ★☆☆☆☆ · **Commands:** ls -a, ls -l

The directory `d` contains a normal file and a hidden file (name starting with `.`).

1. List **all** entries of `d` including hidden ones, except `.` and `..` (`ls -A`).
2. Print the **permissions field** only (first column) of `ls -l d`, one per line, in the
   order `ls -l` lists them.
