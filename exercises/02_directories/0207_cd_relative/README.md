# 0207 · Relative paths with ..

**Topic:** Directories & navigation · **Difficulty:** ★★☆☆☆ · **Commands:** cd, ..

The current directory contains `Datos/Stocks` and `Textos/Cartas/Avisos`.

1. `cd` into `Datos/Stocks` and print the current directory.
2. From there, using **one** `cd` with a **relative** path (with `..`), go to `Textos/Cartas/Avisos`
   and print the current directory.
3. Go back to the previous directory with `cd -` (it prints the directory itself).
