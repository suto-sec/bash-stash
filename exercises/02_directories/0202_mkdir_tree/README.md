# 0202 · Build a directory tree

**Topic:** Directories & navigation · **Difficulty:** ★☆☆☆☆ · **Commands:** mkdir, cd

Create this structure **inside the current directory**:

```
.
├── Datos
│   ├── Inversiones
│   ├── Nominas
│   └── Stocks
└── Textos
    ├── Cartas
    │   ├── Avisos
    │   └── Circulares
    └── Informes
```

The checker compares the resulting files and directories. Nothing needs to be printed.
