# 0205 · Hidden files

**Topic:** Directories & navigation · **Difficulty:** ★☆☆☆☆ · **Commands:** ls -a, ls -A

The directory `cfg` contains normal and hidden files (names starting with `.`).
Print the list of **all** its entries including the hidden ones, **but not** `.` and `..`,
one per line (that's what `ls` does when its output is not a terminal).
