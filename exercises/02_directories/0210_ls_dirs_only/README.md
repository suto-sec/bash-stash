# 0210 · Only the directories

**Topic:** Directories & navigation · **Difficulty:** ★★☆☆☆ · **Commands:** ls -d, */

The current directory has files and subdirectories. Print **only the subdirectories**, one per line,
each followed by `/` (e.g. `docs/`). Hint: the glob `*/` only matches directories, and `ls -d`
lists a directory itself instead of its content.
