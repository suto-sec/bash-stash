# 0212 · tree with limited depth

**Topic:** Directories & navigation · **Difficulty:** ★★☆☆☆ · **Commands:** tree -L, tree -d, --noreport

Print:

1. the full tree of `Datos` (files included), **without** the final summary line
   (`N directories, M files`)
2. the tree of `/usr/share/man`, **directories only**, with **depth 1**, also without the summary line.

See `man tree` (`-L`, `-d`, `--noreport`).
