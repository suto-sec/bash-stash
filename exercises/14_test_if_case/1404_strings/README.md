# 1404 · Comparing strings

**Topic:** test, if & case · **Difficulty:** ★★☆☆☆ · **Commands:** test -z -n = !=

The script receives two arguments (either may be empty: `""`). Print, one per line:

1. `first empty` or `first not empty` (`-z`)
2. `second empty` or `second not empty` (`-n`)
3. `equal` or `different`
4. which one goes first alphabetically (bash `[[ a < b ]]`): print it, or `same` if equal
