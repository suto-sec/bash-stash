# 0105 · Environment variables

**Topic:** Echo, quoting & substitution · **Difficulty:** ★☆☆☆☆ · **Commands:** echo, $VAR

Print your user name, home directory, shell and the list of directories where the shell looks
for executables, using the predefined variables (`USER`, `HOME`, `SHELL`, `PATH`), in this format:

```
User: alumno
Home: /home/alumno
Shell: /bin/bash
Path: /usr/local/sbin:/usr/local/bin:...
```

(Values above are examples: the checker runs your script with a different `HOME`.)
