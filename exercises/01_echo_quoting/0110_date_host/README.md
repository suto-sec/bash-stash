# 0110 · date formats and $HOSTNAME

**Topic:** Echo, quoting & substitution · **Difficulty:** ★★☆☆☆ · **Commands:** date, $HOSTNAME

Print the machine name and the current date/time in these formats (see `man date`):

```
Host: labhost
Date: 2026-06-20
Year: 2026, day of year: 171
```

Use `$HOSTNAME` and `date +FORMAT`.
