# 1738 · Quick refresher: id

**Topic:** Users, groups, sessions, logs & cron · **Difficulty:** ★☆☆☆☆ · **Commands:** id -u

Every user has a number, the UID. `id -u` prints the UID of the current user.

Print your own numeric UID, and nothing else.

Example: it prints something like `1000`.

Hint: `id -u`
