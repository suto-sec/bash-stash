# 1603 · Returning data with echo + $( )

**Topic:** Functions · **Difficulty:** ★★☆☆☆ · **Commands:** $(func), local

`return` only returns a number 0-255. To return **data**, the function prints it and the caller
captures it with `$(...)`.

Write `maximo` (prints the biggest of its arguments) and `media` (prints the integer average of its
arguments). The script prints `max=X avg=Y` for its arguments, using both functions.
