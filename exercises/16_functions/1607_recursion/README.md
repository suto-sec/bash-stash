# 1607 · Recursive functions

**Topic:** Functions · **Difficulty:** ★★★☆☆ · **Commands:** recursion, $( ), local

Write a **recursive** function `fact` (factorial) and a recursive function `hanoi N from to via` that
prints the moves `move disk D from A to C` of the Towers of Hanoi. The script receives N (1-6):
print `N! = ...` and then the moves for N disks from `A` to `C` using `B`.
