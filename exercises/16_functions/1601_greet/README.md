# 1601 · Defining and calling functions

**Topic:** Functions · **Difficulty:** ★☆☆☆☆ · **Commands:** name() { }, function name { }

Define a function `saluda` that prints `Hola, <first argument>!` and a function `linea` that prints
a line of 20 `=` characters. For each script argument call `linea` and then `saluda` with it, and
finish with one more `linea`.
