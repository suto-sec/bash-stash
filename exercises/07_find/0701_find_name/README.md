# 0701 · Searching by name

**Topic:** find · **Difficulty:** ★☆☆☆☆ · **Commands:** find -name

Under the directory `lib` (recursively), find the files whose name starts with `ls` and ends in `.so`.
Print their paths **sorted** (find does not guarantee any order: pipe it to `sort`).

Remember to **quote** the pattern so the shell does not expand it.
