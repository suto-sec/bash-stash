# 1126 · Creating and reading a variable

**Topic:** Variables, arithmetic & environment · **Difficulty:** ★☆☆☆☆ · **Commands:** =, $

A variable stores a value. You create it with `NAME=value` (**no spaces** around the `=`) and read it with `$NAME`.

1. Write this line at the top of your script: `NOMBRE=Ada`
2. Print `Hola, ` followed by the value of the variable. Use `$NOMBRE`, do not type `Ada` again.

```
Hola, Ada
```

Hint: `echo "Hola, $NOMBRE"`
