# 1118 · Word frequencies with an associative array

**Topic:** Variables, arithmetic & environment · **Difficulty:** ★★★☆☆ · **Commands:** declare -A, arrays

The file `palabras.txt` contains one word per line (some repeated). Using an associative array
(`declare -A`), print:

1. one line per **distinct** word, sorted alphabetically, as `word: count`
2. a final line `Distinct: N` (N = number of distinct words)
