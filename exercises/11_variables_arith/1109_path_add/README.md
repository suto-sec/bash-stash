# 1109 · Modifying PATH

**Topic:** Variables, arithmetic & environment · **Difficulty:** ★★★☆☆ · **Commands:** PATH, which, export

The checker gives you a home with an executable `~/bin/saluda` that is **not** in `$PATH`.

1. Print the exit code of `which saluda` (hide its output).
2. Add `$HOME/bin` to the **beginning** of `PATH`.
3. Print `which saluda`, then run `saluda`.
