# 0312 · Moving groups of files

**Topic:** Files, copies & links · **Difficulty:** ★★☆☆☆ · **Commands:** mkdir, mv, *

The current directory is a mess. Organise it:

1. Create the directories `logs`, `images` and `docs`.
2. Move every `*.log` file into `logs`.
3. Move every `.png` and `.jpg` file into `images`.
4. Move every file that starts with `informe` (any extension) into `docs`.

(No file matches more than one rule.)
