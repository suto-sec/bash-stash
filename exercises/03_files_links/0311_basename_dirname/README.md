# 0311 · basename and dirname

**Topic:** Files, copies & links · **Difficulty:** ★★☆☆☆ · **Commands:** basename, dirname

The file `path.txt` contains an absolute path such as `/home/alumno/backups/2026/datos.tar.gz`.
Print:

1. the directory part (`/home/alumno/backups/2026`)
2. the file name (`datos.tar.gz`)
3. the file name without the `.tar.gz` suffix (`datos`)
4. the name of the directory that contains the file (`2026`)

Use `dirname` and `basename`.
