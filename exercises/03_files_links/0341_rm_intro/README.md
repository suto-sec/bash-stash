# 0341 · rm and rm -r

**Topic:** Files, copies & links · **Difficulty:** ★☆☆☆☆ · **Commands:** rm, rm -r

The current directory contains a file `borrar.txt` and a non-empty directory `carpeta`.

1. Delete `borrar.txt` with `rm`.
2. Delete `carpeta` and everything inside it with `rm -r`.

Nothing is printed. There is no recycle bin: deleted files are gone for good.

Hint: `rm file`, and `rm -r directory` for a directory.
