# 0304 · Renaming and moving

**Topic:** Files, copies & links · **Difficulty:** ★☆☆☆☆ · **Commands:** mv

In `Datos/Stocks` there is a file `borrador.txt`.

1. Rename it to `borrador` (without extension).
2. Move it to the parent directory of `Stocks` (i.e. `Datos`).
3. Rename the directory `Datos/Inversiones` to `Datos/Inversion`.

Use `mv` for the three steps (not `cp`).
