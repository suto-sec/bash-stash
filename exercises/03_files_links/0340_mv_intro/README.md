# 0340 · mv: renaming a file

**Topic:** Files, copies & links · **Difficulty:** ★☆☆☆☆ · **Commands:** mv

`mv` moves files, and renaming a file is just moving it to a new name.

The current directory contains `viejo.txt`. Rename it to `nuevo.txt` with `mv`. Afterwards `viejo.txt` must not exist any more. Nothing is printed.

Hint: `mv OLD NEW`
