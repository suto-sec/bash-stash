# 0401 · Creating a .tgz

**Topic:** tar, gzip & compression · **Difficulty:** ★★☆☆☆ · **Commands:** tar -czf

Create a compressed archive `archivo.tgz` in the current directory that contains everything
under the directories `Datos` and `Textos` (paths inside the archive must start with `Datos/` and
`Textos/`, i.e. run `tar` from the current directory with relative paths).
