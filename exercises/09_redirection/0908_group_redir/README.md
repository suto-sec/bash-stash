# 0908 · Redirecting a group of commands

**Topic:** Redirection: > >> 2> < << <<< · **Difficulty:** ★★☆☆☆ · **Commands:** { ...; } > file, ( ... ) > file

Write **one** redirection for a group of commands (`{ ...; } > informe.txt`) so that `informe.txt`
contains:

```
== informe ==
<number of .txt files in docs>
<the names of the .txt files in docs, sorted>
== fin ==
```

Also print `hecho` on the screen afterwards.
