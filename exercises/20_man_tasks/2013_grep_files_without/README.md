# 2013 · Files without a word

**Topic:** Man page tasks · **Difficulty:** ★★★☆☆ · **Commands:** grep

The folder `notas` has several `.txt` files. Print the names of the ones that **do not contain** the word `TODO` anywhere, one per line, as `notas/<name>.txt`, in alphabetical order.

Example: if only `notas/b.txt` lacks `TODO`, the output is `notas/b.txt`.

`grep` has an option to list the files without a match instead of the ones with it: look in `man grep`.
