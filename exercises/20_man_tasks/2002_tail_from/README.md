# 2002 · A file from line 4 onwards

**Topic:** Man page tasks · **Difficulty:** ★★☆☆☆ · **Commands:** tail

`registro.txt` has between 8 and 15 lines. Print it **from its 4th line to the end** (so only the first three lines are left out).

Example: for a file with the lines `a b c d e`, the output is `d` and `e`.

`tail` is usually taught for "the last N lines", but its manual page has a form that counts from the start. Find it with `man tail`.
