# 2014 · A copy that keeps everything

**Topic:** Exam tasks with the manual · **Difficulty:** ★★★☆☆ · **Commands:** cp

The folder `origen` has files and subfolders with different permissions and dates.

Create `copia`, a copy of `origen` (all of it, recursively) in which every file and folder keeps **the same permissions and modification times** as the original.

One `cp` command does it. The options for recursion and for preserving attributes are in `man cp`.
