# 2016 · The permissions as a number

**Topic:** Man page tasks · **Difficulty:** ★★☆☆☆ · **Commands:** stat

The file `programa` is in the current folder. Print its permissions **as an octal number** (for example `755` or `640`) and nothing else.

Do not convert anything yourself: `stat` can print them like that with a format. Look in `man stat` for the format sequences.
