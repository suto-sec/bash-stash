# 2006 · Biggest first

**Topic:** Man page tasks · **Difficulty:** ★★☆☆☆ · **Commands:** ls

The current folder contains only regular files (no folders, nothing hidden), all with different sizes.

Print their names, **one per line, the biggest file first**.

Example: with `a` (10 bytes), `b` (300 bytes) and `c` (20 bytes) the output is `b`, `c`, `a`.

`ls` can sort by size and can print one name per line: both are in `man ls`.
