# 2010 · Everything but the end

**Topic:** Man page tasks · **Difficulty:** ★★☆☆☆ · **Commands:** head

`datos.txt` has between 8 and 14 lines. Print **all of it except its last 3 lines**.

Example: for the lines `1 2 3 4 5` the output is `1` and `2`.

Don't count the lines: `head` accepts a negative number for this. See `man head`.
