# 2009 · The longest line

**Topic:** Man page tasks · **Difficulty:** ★★★☆☆ · **Commands:** wc

Print the **length of the longest line** of `poema.txt` (its number of characters) and nothing else: only the number, no file name.

Example: if the lines have 12, 31 and 7 characters, the output is `31`.

You do not need a loop: `wc` can report this. Look in `man wc` (and remember what it prints next to the number when you give it a file name).
