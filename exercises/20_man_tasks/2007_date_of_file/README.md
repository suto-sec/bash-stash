# 2007 · When was it last changed

**Topic:** Man page tasks · **Difficulty:** ★★☆☆☆ · **Commands:** date

The file `informe.pdf` is in the current folder. Print the **date of its last modification** in the form `YYYY-MM-DD` (year, month and day with leading zeros, separated by hyphens) and nothing else.

Example: for a file last modified on 7 March 2024, the output is `2024-03-07`.

Use `date` for this: it can show the time of a file instead of the current time, and it has a shortcut for the `YYYY-MM-DD` format. Look both up in `man date`.
